SEI H1 — VideoFrame.timestamp vs encoded meta.timestamp

Builds on the working sei-rtc-minimal.html setup (canonical pc.addTrack(), no codec preference forcing, no setParameters tweaks). Adds a side-channel that captures source VideoFrame.timestamp values via a cloned camera track + MediaStreamTrackProcessor (peek-only, never forwarded — so the encoder still sees the original raw camera track and the ScriptTransform pipeline stays intact). Side-by-side compares those source values to the meta.timestamp values surfaced by the worker's transform() callback.

Idle Open in two windows with the same Room ID. The caller window runs the source-timestamp peek + encoder transform; the answerer just confirms the connection.
